
# Oracle Database Administration Labs

This repository contains hands-on Oracle Database Administration labs focused on developing practical database management, backup and recovery, and troubleshooting skills.

## Environment

- Oracle Database 19c Enterprise Edition
- Oracle Linux 8.10
- SQL*Plus and RMAN

## Practical Labs

- [RMAN Restore on the Same Server](./rman-restore-same-server)
- [Control File Creation Without Datafiles](./controlfile-creation-without-datafiles)
